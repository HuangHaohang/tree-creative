# Agent Guides

This directory contains repository guidance that agents must read before making changes.

## Reading Order

1. Read this index.
2. For every development task, read `development-principles.md` before making changes.
3. Read every other guide listed below that is relevant to the task.
4. If instructions conflict, follow the closest applicable `AGENTS.md`, then the more specific guide.

## Guides

- [`development-principles.md`](development-principles.md): mandatory principles for every frontend and backend development task.
- [`tech-stack.md`](tech-stack.md): approved technology stack, deployment model, and decisions still to be confirmed.

Keep this list updated whenever a guide is created, renamed, or removed.

## Intended Contents

Use this directory for durable agent-facing guidance such as:

- Architecture and codebase conventions.
- Development workflows and quality requirements.
- Security and data-handling rules.
- Domain terminology and repository-specific constraints.
- Release, migration, and operational procedures.

Keep product requirements and feature specifications outside this directory so they can live in the project's future documentation area.
